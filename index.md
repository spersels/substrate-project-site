# The Substrate Project

*A designed foundation for machine-authored software — and the problem that demands it.*

AI will write the world's software whether we like it or not. Two futures follow: one where humans retain the **feeling** of control — dashboards, org charts, approvals — while every answer they get is testimony they can't check; and one where humans hold thin but real control, because every consequential action traces **up** to a decision a human ratified and **down** to evidence a human can verify. The difference between the two is invisible until it's tested, the default is the first one, and the window for building the second is closing on a schedule set by discarded provenance and retiring engineers.
